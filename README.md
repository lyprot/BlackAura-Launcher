# BlackAURA Launcher

![BlackAURA Launcher](docs/blackaura-launcher-hero.png)

**Твой Minecraft — твои правила.**

BlackAURA — неофициальный лаунчер Minecraft: Java Edition для Windows. Устанавливайте игру, выбирайте отдельные версии и запускайте сборку BlackAURA с профилями Low, Balanced и Ultra.

## Что нового в 1.0.5

- Обновлённый раздел совместной игры с крупными карточками участников.
- Временные комнаты по приглашению: хозяин и до трёх друзей, без регистрации.
- Понятные статусы подключения, проверка совместимости и сетевые подсказки.
- Уведомления о завершении комнаты и временной недоступности игры.
- Улучшения устойчивости и работы интерфейса.

## Играть вместе

1. Оба игрока обновляют лаунчер и запускают одинаковую сборку через него.
2. Хозяин открывает одиночный мир для сети, вводит показанный Minecraft порт и создаёт комнату.
3. Друг вводит ключ комнаты; хозяин принимает запрос.
4. После готовности соединения друг копирует адрес **из своего лаунчера** и вставляет его в Minecraft: «Сетевая игра» → «Прямое подключение».

Комната рассчитана на четыре человека и работает до пяти часов. Новую комнату можно создавать раз в час; закрытие мира не сбрасывает этот срок. Лаунчер хозяина и гостей должен оставаться открытым. При закрытии мира комната завершается.

Совместная игра проверена для сборки BlackAURA на Minecraft 1.19.4. Другие версии и модификации могут иметь ограничения совместимости. Соединение между разными сетями зависит от их настроек: не каждый роутер или провайдер допускает его. Если адрес для игры не появился, воспользуйтесь диагностикой в комнате. Дополнительную программу устанавливать не нужно.

## Обычная игра

Установки имеют отдельные миры, моды и настройки. Полностью установленную игру можно запускать без интернета, кроме случаев уже полученного уведомления о временном запрете запуска. Новости и обычные уведомления отображаются внутри лаунчера. Визуальные эффекты можно отключить в настройках.

Сборка BlackAURA включает оригинальные моды Loot Cases, Timelapse Sleep и Day & Night. Сторонние модификации принадлежат своим авторам.
